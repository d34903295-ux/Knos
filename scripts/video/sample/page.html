A page in a storyboard

This is a file in the repository, shown as a real page in Chromium.

Three kinds of scene

LineWhat the scene shows
show: url ADDRESSA real page: an address on the web, or a file next to the storyboard.
run: COMMANDThe real output of a command, in a terminal page. It stops the render if the command fails.
show: still FILEA picture, fitted to the frame.

The words

Each scene has say: lines. The voice speaks them one sentence at a time, and the length of every sentence is measured from the audio. A scene lasts as long as its words, with a little quiet before and after.

--- page
say: A scene can show a real page.
show: url sample/page.html
scroll: 1400

The length

The scenes are added up before anything is recorded. If they come to more than 180 seconds the render stops there, and says how many words to cut. The finished file is measured again, and a file that is too long is deleted.

The frame rate

The page is photographed as fast as the browser allows, and each photograph is kept with the moment it was taken. The video is then made at a constant frame rate: where the photographs are far apart, a frame is repeated.

The audio

The narration is joined by counting samples, so it is exactly as long as the scenes. The audio is padded to the length of the video and never trimmed to the shorter of the two.

The subtitles

One cue for each sentence, with the times the voice speaks it. They are written beside the video, and also put inside it.

Where it runs

On Linux, macOS and Windows, with Python, ffmpeg, Playwright and one voice: Piper, which works offline, or the online voices of Microsoft Edge through edge-tts.

Before you publish

Open the contact sheet the render writes beside the video. It shows twelve frames spread over the video, which is enough to see a blank scene or a page that did not load.
